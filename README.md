# Inclus-o-Compartilhada
A plataforma permite consultar atividades testadas, filtradas por idade, série e condição, e enviar novas propostas por um formulário simples, sem exigir conhecimento técnico. Também apresenta indicadores do acervo e um espaço para avaliações, promovendo a colaboração e a melhoria contínua da ferramenta.
